Privacy Policy

Last updated: 24 October 2026

Who uses this tool. Only the video project behind Fino Asks and The Quiet Wire, for its own TikTok accounts. There are no other users.

What is stored. When one of the project's own TikTok accounts is connected, the tool receives an access token, a refresh token and the account's open ID from TikTok. These are stored in a protected file (readable only by the tool) on the project's own server and are used for one purpose only: uploading the project's own videos as drafts to that account.

What is not collected. No analytics, no cookies, no tracking, no advertising, no data about other TikTok users, no followers, comments or messages. This website itself stores nothing and sets no cookies; the callback page only displays the authorization code from the address bar so it can be copied.

Sharing. No data is sold or shared with anyone.

Deletion. Access can be revoked at any time in the TikTok app (Settings → Security → Manage app permissions); the stored tokens are then deleted from the server.

Contact. This tool has no other users, so there is no separate contact channel; access can be revoked at any time in TikTok as described above.
